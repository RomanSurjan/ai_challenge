# Консилиум по Day 9

## Архитектор

Компрессия вынесена в отдельный модуль `context_compression.go`. `Agent` по-прежнему отвечает за один ход диалога, но теперь перед запросом выбирает режим контекста: полная история или `summary + recent messages`.

## Backend

Полная история остается в `JSONMessageStore`, а summary хранится отдельно через `JSONSummaryStore`. После успешного ответа агент сохраняет новую пару сообщений и при накоплении блока обновляет summary. В API добавлен `compression_report`.

## QA

Тесты покрывают обычный запрос, сжатый prompt, обновление summary после ответа, сохранение полной истории, чтение `DAY9_*` настроек, demo без API и JSON-ответ web API. Реальный DeepSeek API в тестах не используется.

## UX

CLI печатает отдельный `Compression report`: режим, full input, compressed input, saved tokens, процент экономии, сколько сообщений покрывает summary и сколько последних сообщений оставлено дословно. Web-чат показывает те же ключевые метрики компактными бейджами под ответом.
