# Консилиум по Day 7

Итоговое решение зафиксировано в `README.md`: для текущего учебного задания выбран JSON, подключенный через интерфейс `MessageStore`.

Причина выбора: JSON проще для чтения, тестирования и ручной проверки, не требует внешнего драйвера и полностью покрывает задачу сохранения одного диалога между запусками. Для будущего расширения интерфейс хранилища оставляет возможность заменить реализацию на SQLite, когда появятся несколько чатов, сессии, метаданные, поиск или выборочная очистка истории.

Роли участников:

- Архитектор сравнил JSON и SQLite и предложил JSON сейчас, SQLite позже при росте требований.
- Backend-разработчик вынес память в отдельное хранилище, которое подключается к `Agent`.
- QA-инженер определил тесты на сохранение, загрузку, перезапуск и ошибки хранения без реальных API-запросов.
- UX/web-разработчик решил не отрисовывать сохраненную историю при открытии web-чата: UI стартует чистым, а контекст подгружается внутри агента перед следующим запросом.
- Документатор обновил README под Day 7 и добавил практическую проверку перезапуска.
