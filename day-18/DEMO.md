# Day 18 — демонстрация единого агента

Сценарий доказывает, что один агент подключается к двум независимым MCP, видит оба набора инструментов и направляет вызовы в правильный сервер.

## 1. Запуск

```bash
cd /Users/romansurzhan/ai_challenge/day-18
docker compose --env-file ../.env up -d --build
docker compose ps
curl -fsS http://127.0.0.1:8083/healthz
curl -fsS http://127.0.0.1:8085/healthz
curl -fsS http://127.0.0.1:8084/healthz
```

Откройте `http://127.0.0.1:8084`. Вверху появится «MCP подключён», а единая панель покажет отдельные колонки GitHub и валют.

## 2. Проверка общего набора инструментов

Отправьте агенту:

> Покажи все мониторинги репозиториев и валютных курсов.

В trace первый этап должен содержать 9 tools с полем `mcp_server`: четыре от `github`, пять от `currency`. Модель вызывает оба list-инструмента в одном диалоге и формирует один итоговый ответ.

## 3. GitHub-монитор

> Создай мониторинг репозитория modelcontextprotocol/go-sdk раз в минуту и останови после двух запусков.

Проверьте в trace вызов `schedule_repository_monitor`, настоящий `schedule_id` и карточку в колонке GitHub. Первый снимок назначается сразу.

## 4. Валютный монитор

> Следи за справочным курсом USD к EUR раз в минуту и остановись после двух проверок.

Проверьте вызов `schedule_exchange_rate_monitor`, отдельный ID и карточку в колонке «Курсы валют». Через 65–75 секунд оба ограниченных расписания должны перейти в `completed` с двумя успешными снимками при доступности внешних API.

## 5. Разовая конвертация

> Конвертируй 125.50 USD в EUR по последнему справочному курсу.

Агент должен выбрать `convert_currency`. Итог использует точные строки `amount`, `rate`, `converted_amount`, `rate_date` и источник из MCP result. Это разовый вызов и он не создаёт расписание.

## 6. Сводки по обоим доменам

> Покажи сводки по последнему GitHub-монитору и мониторингу USD/EUR.

Если ID неизвестны в текущем контексте, агент сначала вызывает соответствующие list tools, затем оба summary tools. GitHub-сводка содержит delta/min/max для stars, forks и open issues; валютная — current/first/last rate, абсолютное и процентное изменение, min/max и дату курса.

## 7. Перезапуск и сохранность

```bash
docker compose restart github-mcp
until curl -fsS http://127.0.0.1:8083/healthz >/dev/null; do sleep 1; done
```

Currency MCP в это время продолжает работать на 8085. Затем аналогично перезапустите `currency-mcp`. Те же ID и снимки должны сохраниться: GitHub-данные находятся в `/data/day18.db`, валютные — в `/data/currency.db`.

## 8. Отмена

Создайте неограниченный монитор, затем попросите:

> Останови мониторинг GBP/EUR и покажи итоговое состояние.

Агент находит ID через `list_exchange_rate_monitors` и вызывает `cancel_exchange_rate_monitor`. Повторная отмена безопасна и возвращает `already_cancelled: true`; история остаётся доступной. Аналогично работает GitHub-инструмент `cancel_repository_monitor`.

## 9. Остановка

```bash
docker compose down
```

Named volume сохраняется. Не добавляйте `-v`, если данные нужны после следующего запуска.
