# Задача: диаметр дерева

## Условие

Дано дерево из `n` вершин, пронумерованных от `1` до `n`.

Диаметр дерева - это максимальное количество ребер на пути между двумя вершинами.

Нужно найти диаметр данного дерева.

## Входные данные

Первая строка содержит одно целое число:

```text
n
```

Количество вершин в дереве.

Следующие `n - 1` строк содержат по два целых числа:

```text
a b
```

Это означает, что между вершинами `a` и `b` есть ребро.

Ограничения:

```text
1 <= n <= 2 * 10^5
1 <= a, b <= n
```

Гарантируется, что входной граф является деревом.

## Выходные данные

Выведите одно целое число - диаметр дерева.

## Пример

Ввод:

```text
5
1 2
1 3
3 4
3 5
```

Вывод:

```text
3
```

В этом примере один из самых длинных путей: `2 -> 1 -> 3 -> 4`, его длина равна `3`.
