### Ответ

Для нахождения диаметра дерева можно использовать стандартный алгоритм с двумя обходами (BFS или DFS):

1. Запускаем обход из произвольной вершины (например, из 1) и находим самую удалённую от неё вершину `u`.
2. Запускаем второй обход из вершины `u` и находим самую удалённую от неё вершину `v`.
3. Расстояние между `u` и `v` будет диаметром дерева.

Реализация на Python:

```python
from collections import deque

def bfs(start, n, graph):
    dist = [-1] * (n + 1)
    dist[start] = 0
    q = deque([start])
    farthest_node = start
    while q:
        node = q.popleft()
        for neighbor in graph[node]:
            if dist[neighbor] == -1:
                dist[neighbor] = dist[node] + 1
                q.append(neighbor)
                if dist[neighbor] > dist[farthest_node]:
                    farthest_node = neighbor
    return farthest_node, dist[farthest_node]

n = int(input())
graph = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    a, b = map(int, input().split())
    graph[a].append(b)
    graph[b].append(a)

# Первый обход
u, _ = bfs(1, n, graph)
# Второй обход
v, diameter = bfs(u, n, graph)

print(diameter)
```

**Пояснение:**
- Используем BFS, так как дерево невзвешенное, и BFS даёт кратчайшие расстояния.
- Первый BFS находит вершину `u`, которая максимально удалена от стартовой.
- Второй BFS из `u` находит максимальное расстояние до любой другой вершины — это и есть диаметр.
- Сложность алгоритма: O(n), что подходит для n до 2·10⁵.

Для нахождения диаметра дерева можно использовать два обхода в глубину (DFS) или в ширину (BFS).

**Идея алгоритма:**
1. Запускаем BFS/DFS из любой вершины (например, из вершины 1).
2. Находим самую удалённую от неё вершину — назовём её `u`.
3. Запускаем BFS/DFS из вершины `u`.
4. Находим самую удалённую от `u` вершину — назовём её `v`.
5. Расстояние между `u` и `v` и будет диаметром дерева.

Это работает, потому что в дереве самая удалённая вершина от произвольной точки всегда является одним из концов диаметра.

---

**Реализация на Python:**

```python
from collections import deque

def bfs(start, adj):
    n = len(adj)
    dist = [-1] * n
    dist[start] = 0
    q = deque([start])
    farthest_node = start
    while q:
        v = q.popleft()
        for to in adj[v]:
            if dist[to] == -1:
                dist[to] = dist[v] + 1
                q.append(to)
                if dist[to] > dist[farthest_node]:
                    farthest_node = to
    return farthest_node, dist[farthest_node]

def main():
    n = int(input())
    adj = [[] for _ in range(n)]
    for _ in range(n - 1):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        adj[a].append(b)
        adj[b].append(a)

    # Первый BFS от вершины 0
    u, _ = bfs(0, adj)
    # Второй BFS от вершины u
    v, diameter = bfs(u, adj)

    print(diameter)

if __name__ == "__main__":
    main()
```

---

**Пояснение:**
- Используем `deque` для очереди BFS.
- Массив `dist` хранит расстояния от стартовой вершины.
- В первом BFS находим вершину `u` — самую дальнюю от стартовой.
- Во втором BFS от `u` находим максимальное расстояние — это и есть диаметр.

**Сложность:**  
Время — O(n), память — O(n).  
Это оптимально для ограничений `n ≤ 2 * 10^5`.

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

// Функция BFS, возвращает пару (самая удалённая вершина, расстояние до неё)
pair<int, int> bfs(int start, const vector<vector<int>>& graph) {
    int n = graph.size();
    vector<int> dist(n, -1);
    queue<int> q;
    
    dist[start] = 0;
    q.push(start);
    
    int farthest_vertex = start;
    int max_dist = 0;
    
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        
        if (dist[v] > max_dist) {
            max_dist = dist[v];
            farthest_vertex = v;
        }
        
        for (int to : graph[v]) {
            if (dist[to] == -1) {
                dist[to] = dist[v] + 1;
                q.push(to);
            }
        }
    }
    
    return {farthest_vertex, max_dist};
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    cin >> n;
    
    if (n == 1) {
        cout << 0 << '\n';
        return 0;
    }
    
    vector<vector<int>> graph(n);
    
    for (int i = 0; i < n - 1; ++i) {
        int a, b;
        cin >> a >> b;
        --a; --b; // переводим в 0-индексацию
        graph[a].push_back(b);
        graph[b].push_back(a);
    }
    
    // Первый BFS: находим самую удалённую вершину от 0 (вершина 1 в 1-индексации)
    auto [u, _] = bfs(0, graph);
    
    // Второй BFS: находим самую удалённую вершину от u

    return 0;

---

### Аналитик  
Формализация:  
Дерево — связный ациклический граф. Диаметр — максимальное расстояние (в рёбрах) между любой парой вершин.  
Ключевая идея:  
1. В любом дереве диаметр можно найти двумя обходами (BFS/DFS):  
   - Из произвольной вершины `s` находим самую удалённую вершину `u`.  
   - Из `u` находим самую удалённую вершину `v`.  
   - Расстояние между `u` и `v` — диаметр.  
Это свойство следует из того, что в дереве самый длинный путь обязательно имеет концы в листьях, и один из концов диаметра будет самой удалённой вершиной от любого старта.

---

### Инженер  
Алгоритм:  
1. Строим список смежности (граф неориентированный).  
2. BFS/DFS от вершины 1 (или любой) — находим вершину `u` с максимальным расстоянием.  
3. BFS/DFS от `u` — находим максимальное расстояние до любой вершины — это и есть диаметр.  

Сложность:  
- Построение списка: O(n).  
- Два обхода: O(n + n) = O(n).  
- Память: O(n) для списков смежности и массивов расстояний.  
Для n ≤ 2·10⁵ — отлично.

---

### Критик  
Проверка крайних случаев:  
- n = 1: рёбер нет, диаметр = 0. Оба BFS вернут 0.  
- n = 2: одно ребро, диаметр = 1.  
- Звезда (центр + n-1 листьев): диаметр = 2 (путь между двумя листьями через центр).  
- Линейное дерево (цепочка): диаметр = n-1.  
- Дерево с большим количеством ветвлений — алгоритм корректен, так как доказано для деревьев.  
- Ограничения: n до 2·10⁵ — рекурсивный DFS может переполнить стек, поэтому используем итеративный BFS/DFS или увеличиваем лимит рекурсии. Лучше BFS на очереди.

---

### Итог команды  
**Решение:**  
1. Читаем n, строим список смежности.  
2. BFS от вершины 1 → находим вершину `u` с максимальным расстоянием.  
3. BFS от `u` → находим максимальное расстояние (диаметр).  
4. Выводим результат.

**Сложность:** O(n) времени, O(n) памяти.  
**Корректность:** гарантируется свойствами дерева.

---

**Реализация (Python):**
```python
from collections import deque
import sys

def bfs(start, adj):
    n = len(adj)
    dist = [-1] * n
    dist[start] = 0
    q = deque([start])
    farthest_node = start
    while q:
        v = q.popleft()
        for to in adj[v]:
            if dist[to] == -1:
                dist[to] = dist[v] + 1
                q.append(to)
                if dist[to] > dist[farthest_node]:
                    farthest_node = to
    return farthest_node, dist[farthest_node]

def main():
    input_data = sys.stdin.read().strip().split()
    n = int(input_data[0])
    adj = [[] for _ in range(n)]
    idx = 1
    for _ in range(n - 1):
        a = int(input_data[idx]) - 1
        b = int(input_data[idx+1]) - 1
        idx += 2
        adj[a].append(b)
        adj[b].append(a)
    
    if n == 1:
        print(0)
        return
    
    u, _ = bfs(0, adj)
    _, diameter = bfs(u, adj)
    print(diameter)

if __name__ == "__main__":
    main()
```

BFS от 4: расстояния: до 2 = 3 (4-3-1-2) → диаметр = 3. Вывод: 3. Верно.
