# Задача: выбор тарифа

## Условие

Онлайн-сервис выбирает один из двух тарифов для обработки клиентских запросов.

Есть прогноз нагрузки на ближайшие 6 месяцев:

| Месяц | Запросов |
|---|---:|
| 1 | 12000 |
| 2 | 18000 |
| 3 | 25000 |
| 4 | 40000 |
| 5 | 55000 |
| 6 | 70000 |

Доступны два тарифа:

## Тариф A

- фиксированная плата: `2000` рублей в месяц;
- стоимость одного запроса: `0.08` рубля.

## Тариф B

- фиксированная плата: `5000` рублей в месяц;
- первые `30000` запросов в месяц включены;
- каждый запрос сверх `30000` стоит `0.03` рубля.

Нужно определить:

1. Какой тариф дешевле в каждом месяце.
2. Общую стоимость каждого тарифа за 6 месяцев.
3. Какой тариф выгоднее выбрать на весь период, если тариф нельзя менять каждый месяц.
4. Начиная с какого количества запросов в месяц тариф B становится дешевле тарифа A.
