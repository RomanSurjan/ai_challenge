---

**2. Утверждение Бориса:**

«Я рыцарь тогда и только тогда, когда Анна — лжец» → V = (V ↔ ¬A).

Упростим:  
- Если V истинно (рыцарь), то утверждение должно быть истинно: V = (V ↔ ¬A) → при V=1 получаем 1 = (1 ↔ ¬A) → ¬A должно быть 1 → A = 0 (лжец).

В обоих случаях получаем **A = 0** (Анна — лжец).  

Проверим:  
- Если A=0 (лжец), то её утверждение «Борис — лжец» ложно → B — не лжец, т.е. B=1 (рыцарь).  
- Тогда из B=1: утверждение Бориса «A и V одного типа» истинно → A=V → 0=V → V=0 (лжец).

**Шаг 1: Введём обозначения.**
Пусть:
- A = true, если Анна рыцарь (говорит правду), иначе A = false (лжец).
- B = true, если Борис рыцарь, иначе B = false.
- V = true, если Виктор рыцарь, иначе V = false.

**Шаг 2: Запишем высказывания формально.**

1. Анна сказала: "Борис - лжец". Это утверждение эквивалентно `¬B`.  
   Так как Анна либо рыцарь (говорит правду), либо лжец (лжёт), то её высказывание должно быть истинно тогда и только тогда, когда она рыцарь.  
   Формула: `A ↔ ¬B`.

2. Борис сказал: "Анна и Виктор одного типа". Это утверждение: `(A == V)`, то есть `(A ∧ V) ∨ (¬A ∧ ¬V)`.  
   Формула: `B ↔ (A ↔ V)`.

3. Виктор сказал: "Я рыцарь тогда и только тогда, когда Анна - лжец".  
   Это утверждение: `V ↔ ¬A`.  
   Формула: `V ↔ (V ↔ ¬A)`.

**Шаг 3: Решаем систему логических уравнений.**

Уравнения:
1. `A ↔ ¬B`
2. `B ↔ (A ↔ V)`
3. `V ↔ (V ↔ ¬A)`

Рассмотрим уравнение 3: `V ↔ (V ↔ ¬A)`.  
Вспомним, что `X ↔ Y` истинно, когда X и Y совпадают.  
Разберём случаи:

- Если V = true, то уравнение: `true ↔ (true ↔ ¬A)`.  
  `true ↔ ¬A` эквивалентно `¬A`. Тогда `true ↔ ¬A` означает `¬A = true`, то есть `A = false`.  
  Значит, при V = true получаем A = false.

- Если V = false, то уравнение: `false ↔ (false ↔ ¬A)`.  
  `false ↔ ¬A` эквивалентно `¬(¬A)` = A (так как `false ↔ X` = ¬X).  
  Тогда `false ↔ A` означает `¬A = true`, то есть `A = false`.  
  Значит, при V = false тоже получаем A = false.

Итак, из уравнения 3 следует, что **A = false** (Анна — лжец) в любом случае.

**Шаг 4: Подставляем A = false в уравнение 1.**

`A ↔ ¬B` → `false ↔ ¬B`.  
`false ↔ X` истинно только если X = false. Значит `¬B = false`, то есть `B = true`.  
Итак, **Борис — рыцарь**.

**Шаг 5: Подставляем A = false и B = true в уравнение 2.**

`B ↔ (A ↔ V)` → `true ↔ (false ↔ V)`.  
`false ↔ V` эквивалентно `¬V`.  
Тогда `true ↔ ¬V` означает `¬V = true`, то есть `V = false`.  
Итак, **Виктор — лжец**.

**Шаг 6: Проверяем согласованность.**

- Анна (лжец) сказала: "Борис — лжец". Но Борис — рыцарь, значит утверждение ложно, что соответствует лжецу. ✓
- Борис (рыцарь) сказал: "Анна и Виктор одного типа". Анна — лжец, Виктор — лжец, они одного типа (оба лжецы). Утверждение истинно. ✓
- Виктор (лжец) сказал: "Я рыцарь тогда и только тогда, когда Анна — лжец".  
  Разберём: "Я рыцарь" = false (Виктор лжец). "Анна — лжец" = true.  
  Утверждение: `false ↔ true` = false. Значит, он солгал. ✓

**Почему другие варианты невозможны?**  
Мы строго вывели из уравнения 3, что A = false, затем из уравнения 1 — B = true, и из уравнения 2 — V = false. Никаких других решений система не допускает, так как каждое уравнение однозначно определяло следующую переменную.

**Ответ:**
- Анна — **лжец**.
- Борис — **рыцарь**.
- Виктор — **лжец**.
